# Prática 3 - Notas dos Alunos

Programa em C que cadastra matrícula e nota de 5 alunos em uma matriz, grava esses
dados em um arquivo de texto (`alunos.txt`) e depois lê o arquivo para confirmar que
as informações foram salvas corretamente.

**Conceitos aplicados:** matrizes, manipulação de arquivos (`fopen`, `fprintf`, `fscanf`, `fclose`).

Compilação:
```
gcc notas.c -o notas
./notas
```
