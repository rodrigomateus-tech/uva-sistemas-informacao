# Prática 6 - Gerenciamento de Velocidade de Veículos

Programa em C que registra a velocidade de 10 veículos em um vetor, grava os valores
em um arquivo `velocidades.txt` e depois lê o arquivo de volta usando `fscanf` em
laço `while` até encontrar o fim do arquivo (`EOF`), exibindo o relatório final.

**Conceitos aplicados:** vetores, manipulação de arquivos, leitura até `EOF`.

Compilação:
```
gcc velocidade.c -o velocidade
./velocidade
```
