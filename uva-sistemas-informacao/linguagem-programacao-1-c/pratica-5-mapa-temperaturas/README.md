# Prática 5 - Mapa de Temperaturas

Programa em C que registra as temperaturas de 3 cidades ao longo de 3 dias usando
uma matriz 3x3, com laços `for` aninhados (um para as cidades/linhas, outro para os
dias/colunas) e exibe o relatório final formatado com uma casa decimal.

**Conceitos aplicados:** matriz 3x3, laços de repetição aninhados, formatação de saída (`%.1f`).

Compilação:
```
gcc temperaturas.c -o temperaturas
./temperaturas
```
