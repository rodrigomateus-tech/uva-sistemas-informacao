# AVA2 - Calculadora de IMC

Programa em C que calcula o Índice de Massa Corporal (IMC) a partir de peso e
altura informados pelo usuário, e classifica o resultado nas faixas da OMS
(abaixo do peso, peso ideal, sobrepeso, obesidade) usando `if / else if`.

Compilação:
```
gcc imc.c -o imc
./imc
```
