# Prática 4 - Gestão de Estoque

Programa em C que aplica a mesma lógica da Prática 3 (matrizes + arquivos) em um
cenário de controle de estoque: cadastra código e quantidade de 5 produtos, salva em
`estoque.txt` e lê de volta para exibir o estoque atualizado.

**Conceitos aplicados:** matrizes bidimensionais, persistência de dados em arquivo `.txt`.

Compilação:
```
gcc estoque.c -o estoque
./estoque
```
