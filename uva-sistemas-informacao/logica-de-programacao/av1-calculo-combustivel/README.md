# AV1 - Cálculo de Despesas de Combustível

Programa em C que calcula o gasto total de combustível em uma viagem a partir da
distância percorrida (km) e do preço do litro, aplicando os conceitos de variáveis,
tipos de dados e operadores.

Compilação:
```
gcc combustivel.c -o combustivel
./combustivel
```
