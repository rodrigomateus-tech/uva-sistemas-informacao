# Prática 1 - Medição de Altura

Programa em C que coleta a altura de 15 pessoas usando um laço `for` e calcula
automaticamente a maior altura, a menor altura e a média do grupo, usando estruturas
de decisão (`if`) dentro do próprio laço de repetição.

**Conceitos aplicados:** laços de repetição, estruturas de decisão, variáveis do tipo `float`.

Compilação:
```
gcc altura.c -o altura
./altura
```
